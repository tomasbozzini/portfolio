## Problem

Practice case: build the lead generation process for a fictional company (RuralSoft) with no manual steps between the search and the CRM.

## Solution

A Make workflow that chains search, extraction, processing with a language model and loading into the CRM: SerpAPI and Apify to find and extract the data, the Claude API to process it, HubSpot as the CRM and Trello for follow-up.
