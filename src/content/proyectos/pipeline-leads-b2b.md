## Problema

Caso de práctica: armar el proceso de generación de leads de una empresa ficticia (RuralSoft) sin intervención manual entre la búsqueda y el CRM.

## Solución

Un flujo en Make que encadena búsqueda, extracción, procesamiento con un modelo de lenguaje y carga en el CRM: SerpAPI y Apify para conseguir y extraer los datos, la API de Claude para procesarlos, HubSpot como CRM y Trello para el seguimiento.
